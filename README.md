# Ambient 3D

**A hardware-accelerated 3D wallpaper engine for Windows.** Built with Python, QtWebEngine and WebGL, it turns your static desktop into a living workstation.

## Features

- **Lives behind your desktop icons.** Hooks in cleanly using the Windows WorkerW/Progman layer: shortcuts, selections and right-clicks on the desktop keep working normally.
- **Pauses for games.** When a game or any fullscreen app is focused, rendering stops automatically to save your system's resources.
- **Your own 3D models.** Load `.obj`, `.gltf`, `.glb` or `.stl` files: an architectural render, a spaceship, a character, anything.
- **Holographic mouse parallax.** Optional: follows your cursor across screens for a real 3D perspective shift and smooth tilt.
- **Tray controls.** Toggle rendering, switch lighting presets, cap the frame rate (30 / 60 / 120 FPS) or quit instantly, with nothing left running in the background.

## Download

Get **Ambient3D-v1.0-Windows-x64.zip** from the [latest release](https://github.com/OmniForgeStudio/ambient3d/releases/latest), or from [omniforgestudio.com/ambient3d](https://omniforgestudio.com/ambient3d.html). Unzip it anywhere and run `Ambient3D.exe`.

Windows may show a SmartScreen warning the first time, because the app isn't signed with a paid certificate: click **More info → Run anyway**.
